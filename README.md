# Site demonstração · 3D Scan Radiologia Odontológica

Proposta de site criada pela **Verus Soluções Inteligentes** (@verus.solutions) para a 3D Scan, em Teixeira de Freitas (BA).

Esta é uma demonstração para apresentação ao cliente, não o site oficial da clínica. A página está marcada como `noindex` para não aparecer no Google.

- `index.html`: página única, sem dependências
- Assistente virtual no canto inferior direito: demonstração com respostas pré-definidas

Para rodar localmente: `py -m http.server 8091` e abra http://localhost:8091
